Ubuntu 介紹

2026-04-02 更新於 2026-05-31 linux
linux ubuntu Debian systemd apt ufw

📢 Ubuntu 是一個基於 Debian 的開源 Linux 發行版，是一個穩定、易於使用並且功能強大的操作系統。無論是作為桌面系統還是伺服器操作系統，它都提供了豐富的功能和廣泛的支持。

🚀版本介紹

  • LTS (Long-Term Support) 版本 LTS 版本每 2 年發布一次，並提供 5 年的更新和安全支持。LTS 版本適合需要長期穩定運行的生產環境
    • Ubuntu 20.04 LTS (2020年4月發布，2025年終止支持)
    • Ubuntu 22.04 LTS (2022年4月發布，2027年終止支持)
    • Ubuntu 24.04 LTS (2024年4月發布，2029年終止支持) ⭐ 最新 LTS 版本
  • 非 LTS 版本 非 LTS 版本每 6 個月發布一次，這些版本提供 9 個月的支持，主要面向希望體驗新技術或保持系統更新的用戶

🚀目錄介紹

完整目錄結構

  • / 根目錄 (Root Directory) 用途：根目錄是整個文件系統的頂層目錄，所有其他目錄都是根目錄的子目錄 。 內容：系統啟動所需的基本文件和目錄結構。
  • /etc 配置文件 (Configuration Files) 用途：存放系統的全局配置文件，包含操作系統和應用程序的設置 。 內容：/etc/passwd（用戶信息）、/etc/network/（網絡設置）、/etc/hostname（主機名設置）等。
  • /home 用戶目錄 (Home Directories) 用途：存放所有普通用戶的個人文件和配置。每個用戶都有一個以其用戶名命名的子目錄 。 內容：例如，/home/username/ 目錄用於存放該用戶的文檔、配置文件等。
  • /tmp 臨時文件 (Temporary Files) 用途：存放臨時文件，這些文件可能由系統或用戶創建，並且通常在系統重啟後會被清除 。 內容：例如，安裝過程中的臨時文件、編譯過程中的中間文件等。
  • /var 可變文件 (Variable Files) 用途：存放那些隨時間變化的文件，如日誌文件、臨時文件、郵件隊列等。 內容：例如，/var/log/（日誌文件）、/var/mail/（郵件隊列）、/var/spool/（排隊任務）。
  • /bin 基本執行檔 (Binary Executables) 用途：存放系統啟動和修復所需的基本命令，這些命令在單用戶模式下也能運行。 內容：如 ls、cp、mv 等基本系統工具。
  • /boot 啟動文件 (Boot Loader) 用途：存放與系統啟動過程有關的文件，如內核、引導加載器等。 內容：vmlinuz（內核映像）、grub/（GRUB 配置文件）、initrd.img（初始化文件）等。
  • /dev 設備文件 (Device Files) 用途：包含對所有硬體設備的抽象層。每個設備（例如硬碟、終端機、打印機）都有一個設備文件。 內容：例如，/dev/sda 代表硬碟，/dev/tty 代表終端設備。
  • /lib 系統庫 (Libraries) 用途：存放系統啟動和運行時所需要的共享庫（.so 文件）和內核模塊。 內容：例如，/lib/x86_64-linux-gnu/ 目錄下的庫文件。
  • /media 可移動介質 (Removable Media) 用途：自動掛載的可移動媒體（如 USB 驅動器、CD/DVD 等）的掛載點。 內容：例如，當插入 USB 設備時，設備會掛載在 /media/username/ 目錄下。
  • /mnt 臨時掛載點 (Temporary Mount Points) 用途：用於掛載臨時的文件系統或手動掛載的設備。不同於 /media，/mnt 通常由系統管理者手動掛載設備。 內容：例如，/mnt 目錄下可能掛載的臨時分區或外部磁碟。
  • /opt 可選軟體 (Optional Software) 用途：存放額外安裝的應用程序或套件。這些程序通常不隸屬於操作系統的一部分。 內容：例如，/opt 目錄下可能存放第三方安裝的應用，如 Google Chrome、Spotify 等。
  • /proc 虛擬檔案系統 (Virtual Filesystem) 用途：存放關於正在運行的內核、進程和系統狀態的虛擬文件。 內容：例如，/proc/cpuinfo（CPU 信息）、/proc/meminfo（內存信息）、/proc/[pid]（進程信息）。
  • /root 超級用戶目錄 (Root User’s Home Directory) 用途：存放系統管理員（root 用戶）的個人文件和配置。/root 目錄的存在與普通用戶的 /home/username 目錄相似。 內容：root 用戶的個人文件和配置。
  • /run 進程信息 (Runtime Data) 用途：存放系統在運行時生成的狀態信息和文件，如進程 ID 文件、系統啟動信息等。/run 在啟動時會被掛載並清空。 內容：例如，/run/lock/（鎖文件）和 /run/user/（用戶運行時數據）。
  • /sbin 系統執行檔 (System Binary Executables) 用途：存放系統管理工具和命令，這些命令通常由系統管理員使用（root 用戶）。這些工具對於系統運行和管理至關重要。 內容：例如，/sbin/init、/sbin/reboot。
  • /srv 服務數據 (Service Data) 用途：存放為系統服務提供的數據。例如，Web 服務的文件可能會存放在此目錄中。 內容：例如，/srv/http/ 可能包含 Apache 或 Nginx 服務的網站文件。
  • /sys 系統設備 (System Devices) 用途：與內核和硬體設備相關的虛擬文件系統，提供有關系統和設備的資訊。 內容：例如，/sys/class/（設備類別信息）、/sys/devices/（硬體設備信息）。
  • /usr 用戶程序 (User Programs) 用途：存放所有用戶應用程序、庫文件、文檔等，這些文件通常與操作系統一起安裝。 內容：例如，/usr/bin/（用戶命令）、/usr/lib/（用戶庫文件）、/usr/share/（共享數據）。

🚀套件管理

Ubuntu 使用 APT （Advanced Package Tool）來管理軟件套件，這是一個強大且易於使用的工具，能夠方便地安裝、升級、移除和管理套件。

⭐更新軟體套件索引

此命令會 更新系統中所有已配置的軟體庫的套件清單 ，確保你安裝或升級的套件是最新的版本。

⭐升級已安裝的軟體套件

此命令會 升級系統上所有已安裝的軟體套件，將其更新為可用的最新版本 ，升級前要注意設定或依賴可能有的衝突 。

  • 升級特定軟體套件

⭐完全升級系統

與 apt upgrade 類似，但 此命令會處理套件的依賴關係，以保證系統和套件之間的依賴性不會中斷，用於需要大規模變更的情況，能夠安裝新套件、刪除不再需要的套件以及更新所有套件。

⭐移除軟體套件

此命令 移除指定的軟體套件，但保留其配置文件 ，以便將來可能會重新安裝。

⭐完全移除軟體套件

此命令 移除軟體套件及其配置文件，這樣該套件的所有配置文件也會被刪除 。

⭐自動移除不再需要的套件

當你移除一個套件時，它 可能會留下某些不再需要的依賴套件（孤立依賴）。這些套件可以使用 autoremove 命令進行自動清理，幫助釋放磁碟空間 。

⭐查詢軟體套件

這個命令可以在軟體庫中搜索特定的套件，並顯示匹配的套件列表。

⭐顯示套件的詳細信息

此命令 顯示指定軟體包的詳細信息，例如版本、依賴、安裝大小、描述等 。

⭐列出已安裝的套件

⭐清理本地緩存

這會清除 /var/cache/apt/archives 目錄中的所有已下載的 .deb 包，釋放磁碟空間。

⭐清理過期的緩存

比 apt clean 更溫和，此命令只會刪除不再需要的過期 .deb 包（即那些在庫中已經不可用的包）。

⭐編輯軟體源列表

此命令允許用戶直接編輯 /etc/apt/sources.list 文件，從而添加或修改軟體源。

🚀網路管理

從 Ubuntu 18.04 開始，Netplan 成為了預設的網絡配置工具，取代了舊有的 ifupdown 和 interfaces 文件。Netplan 是基於 YAML 文件的配置工具，通常用於設置靜態 IP 地址、動態 IP 配置（DHCP）、DNS 和路由等。

  • Netplan 的配置文件通常位於 /etc/netplan/ 目錄下。你會看到一個或多個 YAML 格式的文件
  • nameservers 設定: 設置 DNS 伺服器地址為 Google 公共 DNS 8.8.8.8 和 8.8.4.4。
  • ethernets 設定:
    • 一張主網卡 enp3s0、一張輔助網卡 enp4s0，兩張網卡皆關閉 DHCP功能
    • 兩個外網入網 ip 203.0.113.10 (enp3s0)、198.51.100.10 (enp4s0)
    • 一個出網 ip 203.0.113.10 ，出網 ip 設定 gateway4 網關

🚀使用者帳號管理

在 Ubuntu 中，默認情況下，root 用戶是被禁用的 。這是為了提高安全性，避免使用 root 帳號進行日常操作，因為這樣可能會意外執行有害命令或誤操作系統設定。Ubuntu 倡導使用 sudo （即「以普通用戶身份執行管理命令」）來代替 root 進行管理操作。

⭐創建新用戶

  • 創建用戶帳號資訊 會在 /etc/passwd 文件中為新用戶添加一行。這一行包含了用戶的基本信息（如用戶名、UID、GID、家目錄、默認 shell 等）。
  • 創建用戶的家目錄 會創建一個位於 /home/用戶名 的目錄，並將該目錄設置為該用戶的家目錄。這是用戶登錄後的默認工作目錄。

⭐用戶 root 權限管理

🚀防火牆管理

在 Ubuntu 中，防火牆的管理通常是通過 UFW （Uncomplicated Firewall）來進行的。UFW 是一個簡單且易於使用的前端工具，它是 iptables 的封裝，使得防火牆設置更容易。新安裝的系統默認情況下 UFW 防火牆是禁用的 。這是為了確保系統安裝後，能夠讓用戶快速配置和使用系統，不會因為防火牆的阻擋而造成不必要的麻煩。

可以選擇直接使用 iptables 來配置防火牆，而不使用 UFW

    • 改進的防火牆規則
    • 更嚴格的系統加固設置
    • AppArmor 和 SELinux 的改進

  • 性能優化

    • 啟動速度更快
    • 內存管理改進
    • 系統資源使用效率提高
