Linux 指令介紹

2026-04-04 更新於 2026-06-03 linux
linux DevOps

📢 Linux 指令是系統管理和開發的基本工具，包括檔案操作、進程管理、系統監控等常用命令。

Ctrl + A切到命令句首
Ctrl + E切到命令句尾

🚀指令說明

指令功能說明
man查看指令說明
help查看指令說明(內建命令)
which查找指令所在的完整路徑

🚀檔案和目錄操作

指令功能說明
cd切換工作目錄路徑
ls列出目錄資訊
tree以樹形結構列出目錄結構。sudo apt install tree
pwd列出目前所在目錄位置
指令功能說明
mkdir創建目錄(可批量創建)
mv移動目錄或檔案位置、更改檔名或目錄名
rm刪除檔案或目錄
cp複製檔案或目錄
find查詢檔案或目錄，可用正規表達式
touch創建空檔案(可批量創建)。可用其它指令創建檔案
test檢測檔案或目錄的屬性。常用於 shell 腳本
rename更改多個檔名或目錄名。sudo apt install rename，不常用
rmdir刪除空目錄。不常用
file判斷檔案類型

🚀檔案和文本處理

符號用法說明
>重新定向符號，用於把指令產生文本儲存在文件內，會覆蓋原本內容
>>重新定向符號，用法同>，但不會覆蓋，而是在原本內容末尾寫入
<重新定向符號，反向把文本內容作用於前面指令
\跳脫符號，用於讓特殊字元不會被當成參數或特定用法使用
指令功能說明
cat印出檔案內容，或修改、寫入、垂直合併 文件
zcat印出檔案內容，或修改、寫入、垂直合併 文件，主要用於壓縮檔，用法參考 cat
head印出檔案或文本頭部內容
tail印出檔案或文本尾部內容
cut擷取檔案或文本指定字段後印出
split分割檔案
paste合併檔案或文本後列出，水平合併，並且適合文件轉置
sort對文本內容進行排序後印出
uniq去除連續重複的文本內容，通常搭配sort 使用
wc計算文本的(字數、行數、位元組數)後印出
tr用於文本字符轉換、刪除特定字元後印出
join對文本進行水平擴展 的合併後印出
diff比較文件差異
grep查找符合條件的檔案或文本後印出，重要，可用正規表達式
ripgrep比 grep 更快速，適用大規模檔案和多檔案，sudo apt install ripgrep
sed依照指定模式或腳本處理檔案或文本，重要，可用正規表達式
awk依照條件打印檔案或文本內容，重要，可用正規表達式
md5sum印出檔案的MD5哈希值，通常用來驗證檔案是否一致，推薦使用 shasum
vim文本編輯工具。可用正規表達式，sudo apt install vim
vim 操作(按鈕)進入/退出編輯模式
i在光標位置，進入編輯模式，常用
a在光標位置後，進入編輯模式
o在光標位置向下新增一行，進入編輯模式
esc離開編輯模式 ，按下後輸入退出指令即可退出
vim 操作(命令)命令模式操作
:wq離開命令模式 ，儲存後退出
:q!離開命令模式 ，不儲存退出
0光標位置切換，切換到行首
$光標位置切換，切換到行尾
G光標位置切換，切換到最後一行
nG光標位置切換，切換到第 n 行
gg光標位置切換，切換到第一行
yy複製 光標所在行
:3,10y複製 3到10行
dd刪除/剪下 光標所在行，刪除內容會暫存
:3,10d刪除/剪下 3到10行，刪除內容會暫存
p在光標行貼上複製或暫存內容
/搜尋內容光標往下搜尋
?搜尋內容光標往上搜尋
n搜尋結果，下一個匹配的
N搜尋結果，上一個匹配的
:3,100s/AA/BB/g3到100行，AA 取代 BB
:1,$s/AA/BB/g1到最後一行，AA 取代 BB，等同 :%s/AA/BB/g

🚀進程管理

指令功能說明
ps列出目前進程
pstree以樹狀列出目前進程
kill中止進程
killall使用進程名中止進程
job印出背景執行的任務
timeout限制指令執行時間
  • 孤兒進程 指其原父進程已經終止，但該進程仍然在運行，因此被系統的 init 進程（PID 1）接管，該進程的父進程 PPID 欄位改為 1 (init 進程) 處理：
    • 孤兒進程不會造成資源浪費，因為它們的父進程（init）會將其處理掉。通常不需要手動處理孤兒進程，因為 init 會定期收回它們。
  • 殭屍進程 指那些已經完成執行的進程，狀態為 Z ，但父進程還沒調用系統讀取子進程的退出狀態。由於父進程未清理，這些進程仍會保留在進程表中，佔用系統資源 處理：
    • 重啟父進程：如果知道哪個父進程沒有清理子進程，可以嘗試重啟該父進程。
    • 終止父進程：如果父進程無法處理殭屍進程，可以手動終止父進程。終止父進程後，系統會將子進程的父進程設為 init（PID 1），並清理這些殭屍進程。
