Prometheus 介紹

2026-05-02 更新於 2026-06-11 監控管理
prometheus DevOps monitoring

📢 Prometheus 是開源的時間序列監控系統 ，用於收集和存儲指標數據，提供強大的查詢語言 PromQL，廣泛應用於監控應用程式、伺服器和容器環境。

  • 核心特性
    • 以時間序列 格式儲存指標數據
    • 強大的 PromQL 查詢語言
    • 支援多種 Exporter 收集數據
    • 提供直觀的 Web UI 和 API
    • 輕量級且易於部署

📕 Docker-Compose 快速啟動

⭐ 建立 docker-compose.yml

使用 docker-compose 是最快速的部署 方式，只需一個設定檔即可啟動完整的 Prometheus 服務。

📕 Prometheus 主要設定檔

⭐ prometheus.yml 設定說明

prometheus.yml 是 Prometheus 的核心設定檔 ，定義了全域設定 、抓取職務 和告警規則 。

⭐ 關鍵設定參數

參數說明預設值
scrape_intervalPrometheus 從 Exporter 抓取指標 的間隔時間15s
evaluation_interval評估告警規則 的間隔時間15s
scrape_timeout單次抓取 的超時時間10s
job_name職務名稱，用於識別抓取目標必須指定
targets要抓取的目標地址 （IP:埠號）必須指定

📕 常見 Exporter

⭐ Exporter 介紹

Exporter 是用來將應用程式、伺服器、資料庫等的指標 暴露為 Prometheus 可識別格式的服務。以下是常見的 Exporter：

Exporter 名稱說明埠號官方倉庫
Node Exporter監控主機系統指標 （CPU、記憶體、磁碟、網路等），支援多個作業系統9100點我
cAdvisor容器監控 工具，支援 Docker 和 Kubernetes8080點我
MySQL Exporter監控 MySQL 資料庫指標9104點我
PostgreSQL Exporter監控 PostgreSQL 資料庫指標9187點我
Redis Exporter監控 Redis 快取伺服器9121點我
Nginx Exporter監控 Nginx 網頁伺服器9113點我
JMX Exporter監控 Java 應用程式指標5556點我
Blackbox Exporter黑盒監控 ，用於監控服務可用性9115點我

📕 Prometheus 服務網址路由

⭐ Web UI 和 API 路由

假設 Prometheus 運行在 http://localhost:9090 ，以下是常用的路由：

路由說明
http://localhost:9090/Prometheus 首頁和 Web UI
http://localhost:9090/graph查詢頁面 ，可輸入 PromQL 查詢指標
http://localhost:9090/api/v1/queryAPI 接點 ，用於 PromQL 瞬時查詢
http://localhost:9090/api/v1/query_rangeAPI 接點 ，用於 PromQL 範圍查詢
http://localhost:9090/api/v1/seriesAPI 接點 ，列出符合標籤的時間序列
http://localhost:9090/api/v1/label/name/valuesAPI 接點 ，列出所有指標名稱
http://localhost:9090/metricsPrometheus 自身暴露 的指標（可被抓取）
http://localhost:9090/-/healthy健康檢查 端點
http://localhost:9090/-/ready就緒檢查 端點

📕 使用建議

  • 定期備份 TSDB 數據： Prometheus 的時間序列數據重要，定期備份 /prometheus 目錄
  • 設定合理的保留期 ： 使用 –storage.tsdb.retention.time 設定數據保留時間
  • 使用 Grafana 可視化： 與 Prometheus 整合建立監控儀表板
  • 監控 Prometheus 本身： 透過 /metrics 路由監控健康狀態和效能
