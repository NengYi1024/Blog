Ansible 介紹與使用

2026-04-08 更新於 2026-05-31 腳本
ansible DevOps

📢 Ansible 是開源自動化工具，基於無代理架構，用於配置管理、應用部署、任務編排和跨主機協調。

🚀ansible 設定介紹

  • 設定檔案或目錄 :
  • ansible.cfg : 主要設定檔 。下列為參考設定

  • inventory 檔案/目錄 : 用於記錄 ansible 連線主機列表 。可為單一檔案，也可使用目錄來存放不同用途的連線主機列表

    • inventory 作為檔案
    • inventory 作為目錄

  • playbook 檔案/目錄 : 用於定義主要執行任務 ，通常搭配 roles 一起使用。

  • roles 檔案/目錄 : 用於定義任務的工作內容 ，通常搭配 playbook 一起使用。使用 playbook 範例 yml 會依照任務設定執行 set1 、set2
    • roles/config/set1/task/main.yml
    • roles/config/set2/task/main.yml

⭐ansible-playbook 執行輸出

  • 執行結果回傳 :

    • rc (返回碼) : 每個任務執行結果。使用 shell/command 模組回傳 0 表示成功，非 0 表示失敗。使用 其它模組或不回傳值的 shell 指令 回傳值就不會是 0 和 非 0 ，因此可能 rc 值為空或未定義，另用其它參數來做為任務成功的輸出。
    • stdout (標準輸出) : shell 指令或模組執行成功時會輸出終端上顯示的成功訊息 ，如未有訊息可能會以狀態更改來輸出。
    • stderr (標準錯誤) : 同 stdout (標準輸出)差別為是輸出執行錯誤的訊息。

  • 輸出方式 :

指令/腳本使用說明顯示
預設指令只顯示任務執行狀態任務執行結果
預設指令帶 -v簡略詳細模式 ，顯示比預設多一些執行訊息預設輸出包含 stdout (標準輸出)
預設指令帶 -vv更多詳細模式 ，顯示更詳細過程，和模組返回值預設輸出包含 stdout (標準輸出)
預設指令帶 -vvv更多詳細模式 ，顯示更詳細過程，和模組返回值預設輸出包含 rc (返回值)、stdout (標準輸出)、stderr (標準錯誤)
腳本中使用 register + debug 模組register 儲存單一任務執行結果，再用 debug 模組定義 msg 輸出訊息自定義輸出結果

⭐ansible-playbook 模組使用介紹

  • playbooks :
  • roles :
    • setup 模組 : 用於手動收集主機系統資訊。輸出結果不用搭配 register
  • set_fact 模組 : 用於動態設置和更新變數
  • expect 模組 : 用於指令執行時出現交互模式可自動填入，要搭配 command 模組使用
  • include_tasks 模組 : 用於細分任務
  • command 模組 : 用於執行簡單 shell 指令
  • shell 模組 : 用於執行複雜 shell 指令
  • service 模組 : 用於管理系統服務
  • apt 模組 : 用於套件管理
  • file 模組 : 用於檔案或目錄的操作
  • stat 模組 ，搭配 debug 模組輸出 : 用於確認檔案或目錄狀態
  • copy 模組 : 用於複製檔案或目錄
  • synchronize 模組 ，用於同步文件。執行需安裝 rsync 指令
  • blockinfile 模組 ，用於對多行檔案的修改或新增
  • lineinfile 模組 ，用於單行檔案的修改或新增
  • ufw 模組 : 用於防火牆規則管理，使用前確保 ufw 服務啟用
  • template 模組 : 用於創建固定內容的檔案
  • template 模板使用 templates/config.j2 :
  • dict 參數使用 vars/main.yml :
  • 常用參數 :
    • register、when : register 將任務結果儲存；when 控制任務執行條件，符合才執行
  • tags : 用於為任務添加標籤，使執行時可以執行特定任務
  • notify : 用於執行任務後通知 handlers 的任務，範例可參考 lineinfile 模組介紹
  • vars 和 set_fact 模組 : 用於創建變數使用。vars 靜態變數不能修改；set_fact 模組 動態變數可在執行過程修改
  • loop、with_dict : 用於遍歷變數的
  • become、become_user : 用於執行時改變使用者
  • ignore_errors : 用於忽略執行錯誤，使錯誤發生不會中斷整個 playbook 腳本

⭐常用工具

  • sshpass 工具 : 自動化密碼輸入工具，需額外安裝 sshpass 工具
  • sshpass.rb : MAC 上 homebrew 自動化腳本
  • ansible vault 內建工具 : 加密私密訊息
