🔨 AWS API Key 配置

⭐️ 認證方式

Terraform 提供多種方式連接 AWS：

  • 環境變數 （開發用）
    • 在終端設定 AWS_ACCESS_KEY_ID 和 AWS_SECRET_ACCESS_KEY
  • AWS 認證文件 （推薦）
    • 存放於 ~/.aws/credentials
  • IAM 角色 （生產環境）
    • EC2 執行個體或 Lambda 的角色

⭐️ 刪除資源

三種刪除方式：

  1. 刪除 tf 文件中的資源定義 （推薦）

    • 從 main.tf 刪除 resource “aws_instance” “web_server” {} 塊
    • 執行 terraform apply ，Terraform 自動刪除實際資源
    • 狀態文件同步更新

  2. 使用 terraform destroy

    • terraform destroy 刪除所有資源
    • terraform destroy -target=aws_instance.web_server 刪除特定資源

  3. 使用 terraform state rm

    • 只移除狀態文件中的資源記錄，不刪除實際資源
    • 適用於誤導入或需要解除 Terraform 管理的場景

🔨 最佳實踐

  • 模組化
    • 將相關資源組織成模組，提高代碼可重用性
  • 遠端狀態
    • 使用 Terraform Cloud、S3 或其他後端儲存狀態，便於團隊協作
  • 變數和輸出
    • 使用變數減少硬編碼，使用輸出暴露重要信息
  • 版本控制
    • 將 Terraform 配置提交到 Git，使用分支和 PR 進行代碼審查
  • 加標籤
    • 為所有資源添加一致的標籤，便於成本跟蹤和資源管理
  • 測試
    • 在開發環境先測試，使用 terraform plan 審查變更
